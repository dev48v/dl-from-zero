DeepLearningFromZero · Day 52

🖇 CLIP (Contrastive Language–Image Pre-training) — instead of training an image classifier on a fixed list of labels, CLIP trains two encoders at once — an image encoder (a ViT or ResNet) and a text encoder (a transformer) — so that a picture and its caption land at the same point in one shared embedding space. The training signal is dead simple: take a batch of N (image, caption) pairs, embed all N images and all N captions, L2-normalize every vector, and form the N×N matrix of cosine similarities between every image and every caption. Exactly N of those N² cells are true pairs — they sit on the diagonal — and the other N²−N are mismatches. The contrastive loss just says: make the diagonal the largest entry in its row and in its column — pull each image toward its own caption and push it away from every other caption in the batch, symmetrically (a cross-entropy over the rows and over the columns), with a learned temperature scaling the similarities before the softmax. No hand-labelled classes at all — the caption is the supervision, and the web has ~400M such pairs for free. The payoff is zero-shot classification: to classify a brand-new image with a set of labels you’ve never trained on, just write each label as a sentence — “a photo of a {cat}”, “a photo of a {dog}” — encode those prompts with the text tower, encode the image with the image tower, and pick the nearest caption. The same shared space also gives image↔text retrieval for free, and CLIP’s text encoder is what conditions DALL·E 2 and Stable Diffusion and powers open-vocabulary detection/segmentation. Below: watch a live batch’s images and captions align in a shared space as you “train” it, see the N×N similarity matrix light up its diagonal while the contrastive loss drops, and run a zero-shot classifier — all computed live in the browser from toy deterministic embeddings.

🔨 Build it yourself

    
CLIP is two ordinary encoders glued by one loss. We’ll build it piece by piece: two towers projecting to a shared dim, the L2-normalized embeddings, the temperature-scaled cosine-similarity matrix, the symmetric contrastive loss that is the whole idea, a minimal training step, and finally zero-shot classification from plain-English label prompts.

    
    
      
  1. 
        
    1
    Two encoders that project into one shared space
    
        
    An image encoder (a ViT or ResNet) and a text encoder (a transformer) each output their own feature vector, then a small linear projection maps both into the same D-dim embedding space. A single learnable scalar logit_scale stores the temperature as log(1/τ).
    
        
    import torch, torch.nn as nn, torch.nn.functional as F

class CLIP(nn.Module):
    def __init__(self, image_encoder, text_encoder, d_img, d_txt, D=512):
        super().__init__()
        self.image_encoder = image_encoder      # e.g. a ViT  -> (B, d_img)
        self.text_encoder  = text_encoder       # a transformer -> (B, d_txt)
        self.img_proj = nn.Linear(d_img, D, bias=False)  # into shared space
        self.txt_proj = nn.Linear(d_txt, D, bias=False)
        # learned temperature, stored as log(1/tau); init ~ log(1/0.07)
        self.logit_scale = nn.Parameter(torch.tensor(2.6592))
    
      
    2. 
      
  2. 
        
    2
    Encode a batch & L2-normalize onto the unit sphere
    
        
    Embed all N images and all N captions, then normalize every vector to length 1. After normalization a dot product is the cosine similarity, so all vectors live on the unit hypersphere and only their direction matters.
    
        
    def encode(self, images, tokens):
    img = self.img_proj(self.image_encoder(images))   # (N, D)
    txt = self.txt_proj(self.text_encoder(tokens))    # (N, D)
    img = F.normalize(img, dim=-1)   # unit vectors -> dot = cosine
    txt = F.normalize(txt, dim=-1)
    return img, txt
    
      
    3. 
      
  3. 
        
    3
    The N×N similarity matrix, scaled by temperature
    
        
    One matrix multiply gives every image-vs-caption cosine similarity. Multiply by logit_scale.exp() (that’s 1/τ) to turn similarities into logits — a small τ sharpens the softmax and pushes negatives harder. Clamp the scale so it can’t explode.
    
        
    def logits(self, img, txt):                 # img,txt: (N, D)
    scale = self.logit_scale.exp().clamp(max=100.0)   # = 1/tau
    logits_per_image = scale * img @ txt.t()   # (N, N): row i = image i
    logits_per_text  = logits_per_image.t()    # (N, N): row j = caption j
    return logits_per_image, logits_per_text
    
      
    4. 
      
  4. 
        
    4
    The symmetric contrastive loss — the whole idea
    
        
    The correct match for image i is caption i, so the labels are just arange(N) — the diagonal. Cross-entropy over each row makes each image pick its caption (image→text); cross-entropy over each column makes each caption pick its image (text→image); average them. That symmetry is the contrastive loss (InfoNCE, both directions) — every off-diagonal cell in the batch is a negative.
    
        
    def clip_loss(self, img, txt):
    N = img.shape[0]
    logits_per_image, logits_per_text = self.logits(img, txt)
    labels = torch.arange(N, device=img.device)   # diagonal = truth

    loss_i2t = F.cross_entropy(logits_per_image, labels)  # each image -> its text
    loss_t2i = F.cross_entropy(logits_per_text,  labels)  # each text  -> its image
    return (loss_i2t + loss_t2i) / 2                       # symmetric InfoNCE

    The training loop — captions are the labels
    
        
    No class annotations anywhere: a batch is just (image, caption) pairs scraped from the web. Bigger batches mean more negatives per step, which is why CLIP trains with very large batches (32k+). That’s the entire recipe — scale it to ~400M pairs and zero-shot emerges.
    
        
    opt = torch.optim.AdamW(model.parameters(), lr=5e-4, weight_decay=0.2)

for images, captions in dataloader:          # (image, text) pairs, NO labels
    tokens = tokenize(captions)
    img, txt = model.encode(images, tokens)
    loss = model.clip_loss(img, txt)         # symmetric contrastive
    opt.zero_grad(); loss.backward(); opt.step()
    model.logit_scale.data.clamp_(max=4.6052)   # keep 1/tau <= 100

# big batches = more negatives per image = a stronger signal.

    Zero-shot classification — the payoff
    
        
    To classify with labels you never trained on: write each label as a prompt, encode the prompts once with the text tower to get a set of “class vectors,” encode the image with the image tower, and take the nearest caption. No fine-tuning, no new head — the shared space already lines images up with words.
    
        
    @torch.no_grad()
def zero_shot(model, image, class_names):
    prompts = [f"a photo of a {c}." for c in class_names]   # prompt engineering
    txt = F.normalize(model.txt_proj(model.text_encoder(tokenize(prompts))), dim=-1)
    img = F.normalize(model.img_proj(model.image_encoder(image[None])), dim=-1)

    sims  = (img @ txt.t()).squeeze(0)          # cosine to each class prompt
    probs = (sims / TEMPERATURE).softmax(dim=-1)
    return class_names[int(probs.argmax())], probs   # nearest label wins

# class_names can be ANYTHING you can phrase in words -> open-vocabulary.
# same embeddings also give image<->text retrieval for free.

🎉 Day 52 of DeepLearningFromZero done.
CLIP trains an image encoder and a text encoder together so a picture and its caption land at the same point in one shared embedding space. Over a batch of N (image, caption) pairs it builds the N×N cosine-similarity matrix and applies a symmetric contrastive loss — a temperature-scaled softmax cross-entropy over the rows and the columns — that pulls the diagonal (true pairs) up and pushes every off-diagonal negative down, using the caption itself as the only label. At scale (~400M web pairs) this unlocks zero-shot classification: embed the image, embed label prompts like “a photo of a {label}”, and pick the nearest — no task-specific training, fully open-vocabulary — plus image↔text retrieval, and a text encoder that conditions DALL·E 2 / Stable Diffusion and drives open-vocab detection & segmentation. 👉 Tomorrow, Day 53: BERT & Masked LM — bidirectional pre-training that predicts masked-out tokens, the recipe that made transfer learning the default for NLP.
