DeepLearningFromZero · Day 58

🌈 Spectral Normalization (SN) — a linear layer y = Wx can stretch its input by a factor that depends on direction, and the worst-case stretch — the largest ∥Wx∥/∥x∥ over all x — is exactly the spectral norm σ(W), the largest singular value of W, and it is the layer’s Lipschitz constant. In a GAN the discriminator is trained adversarially and its weights keep growing, so σ blows up, gradients explode, and training collapses; WGAN patched this with crude weight-clipping (kills capacity) then a gradient penalty (an extra backward pass). Spectral Normalization (Miyato et al., 2018) is the cheap, direct fix: divide every weight matrix by its own spectral norm, WSN = W / σ(W), so each layer is exactly 1-Lipschitz (σ = 1) — and a stack of 1-Lipschitz maps is itself 1-Lipschitz. Computing a full SVD every step would be far too slow, so SN estimates σ with a single step of power iteration per forward pass, warm-started from the previous step’s singular vector: u ← Wv/∥Wv∥, v ← Wᵀu/∥Wᵀu∥, σ ≈ uᵀWv — almost free. Below, edit a small weight matrix W, watch power iteration’s u, v and its σ-estimate converge to the true singular value by hand; see W map the unit circle to an ellipse whose longest semi-axis is exactly σ, while W/σ maps it to an ellipse that fits inside the unit circle (1-Lipschitz); then drive a mock training loop and watch an unnormalized σ explode while SN pins it at 1 — every matrix op, the power iteration, the singular values and the mappings computed by hand, no libraries.

Three ways to make a discriminator 1-Lipschitz
Weight clipping (WGAN)
Clamp every weight into [−c, c] after each step. Cheap but blunt: it caps the wrong quantity, wastes capacity, and pushes weights to the clip bounds — hard to tune, poor gradients.
Gradient penalty (WGAN-GP)
Add a penalty pushing ∥∇D∥→1 on interpolated samples. Enforces Lipschitz softly and well, but needs an extra backward pass — noticeably more compute per step.
Spectral normalization
W/σ(W) makes each layer exactly 1-Lipschitz — a hard guarantee, no capacity loss, no extra backward pass. One power-iteration step per forward is all it costs.

🔨 Build it yourself

    
Spectral normalization is a tiny wrapper around a weight matrix. We’ll build the whole thing from scratch: matrix–vector products, the power-iteration estimate of the top singular value, the W/σ divide that makes a layer 1-Lipschitz, the forward-pass wrapper that runs one warm-started power-iteration step per call exactly as the SNGAN paper does, and a check against a real SVD — every operation by hand.

    
    
      
  1. 
        
    1
    A linear layer’s Lipschitz constant IS its spectral norm
    
        
    For y = Wx, the largest possible stretch ∥Wx∥/∥x∥ over all x is the top singular value σ(W). That worst-case stretch is precisely the Lipschitz constant of the layer w.r.t. the L2 norm.
    
        
    import numpy as np

W = np.array([[1., 2.],
              [3., 4.]])            # a (flattened) layer weight matrix

# Lipschitz(y=Wx) w.r.t. L2  ==  sigma(W)  ==  max singular value
#     ||W x|| <= sigma(W) * ||x||     for EVERY x
def matvec(W, x):  return W @ x     # forward map (by hand: sum_j W_ij x_j)

  2. 
        
    2
    Power iteration — the top singular value, cheaply
    
        
    A full SVD is O(d³) — too slow to run every step. Power iteration finds only the top singular pair by alternately mapping through W and Wᵀ and re-normalizing. Each pass is a couple of matrix–vector products, O(d²).
    
        
    def spectral_norm(W, v, n_iter=1):
    for _ in range(n_iter):
        u = W @ v;   u /= np.linalg.norm(u) + 1e-12   # left  singular vec
        v = W.T @ u; v /= np.linalg.norm(v) + 1e-12   # right singular vec
    sigma = u @ (W @ v)          # u^T W v  ->  top singular value
    return sigma, u, v

  3. 
        
    3
    Normalize: divide by σ → a 1-Lipschitz layer
    
        
    Divide the whole matrix by its spectral norm. The result has σ(W/σ) = 1, so ∥(W/σ)x∥ ≤ ∥x∥ for every x — the layer can no longer stretch, only rotate/shrink.
    
        
    def sn_weight(W, v):
    sigma, u, v = spectral_norm(W, v, n_iter=1)
    return W / sigma, v          # W_SN: sigma == 1  ->  exactly 1-Lipschitz

  4. 
        
    4
    The SN forward-pass wrapper (SNGAN)
    
        
    The real trick: run only one power-iteration step per forward pass, warm-started from the vector v stashed on the last pass. Because W barely changes between steps, that single step tracks σ accurately — SN is essentially free.
    
        
    class SNLinear:
    def __init__(self, W):
        self.W = W
        self.v = np.random.randn(W.shape[1])      # persistent estimate
        self.v /= np.linalg.norm(self.v)
    def forward(self, x):
        u = self.W @ self.v;  u /= np.linalg.norm(u) + 1e-12
        v = self.W.T @ u;     v /= np.linalg.norm(v) + 1e-12
        self.v = v                                 # WARM-START next call
        sigma = u @ (self.W @ v)                   # 1-step sigma estimate
        W_sn  = self.W / sigma                     # 1-Lipschitz weight
        return W_sn @ x                            # spectrally-normed layer

    Verify against a real SVD
    
        
    Power iteration should converge to the true top singular value, and W/σ should have top singular value exactly 1. Check both against NumPy’s SVD — the same checks the live demo runs.
    
        
    sigma_true = np.linalg.svd(W, compute_uv=False)[0]   # largest singular value
sigma_pi, u, v = spectral_norm(W, v0, n_iter=50)
assert abs(sigma_pi - sigma_true) < 1e-6             # PI converges to truth
W_sn, _ = sn_weight(W, v0)
assert abs(np.linalg.svd(W_sn, compute_uv=False)[0] - 1.0) < 1e-6   # 1-Lipschitz

    A 1-Lipschitz discriminator — why the GAN stays stable
    
        
    Wrap every layer. Because a composition of 1-Lipschitz maps is 1-Lipschitz, the whole discriminator is 1-Lipschitz — its gradients w.r.t. the input are bounded, so the adversarial min–max game can’t send σ (and the gradients) to infinity. No capacity-killing weight clip, no extra backward pass.

for real, fake in batches:              # standard GAN training

🎉 Day 58 of DeepLearningFromZero done.
Spectral Normalization caps a layer’s Lipschitz constant by dividing its weight matrix by its own spectral norm σ(W) — the largest singular value, i.e. the worst-case stretch of the unit circle into an ellipse. W/σ makes each layer exactly 1-Lipschitz (the ellipse fits inside the unit circle), and stacking 1-Lipschitz maps keeps the whole discriminator 1-Lipschitz — bounded gradients, stable GAN training. The genius is efficiency: rather than an O(d³) SVD every step, SN runs a single power-iteration step per forward pass (u←Wv/∥Wv∥, v←Wᵀu/∥Wᵀu∥, σ≈uᵀWv), warm-started from the previous v, so it’s almost free. Unlike WGAN’s weight clipping (kills capacity) or gradient penalty (extra backward pass), SN is a hard 1-Lipschitz guarantee at essentially no cost — which is why SNGAN and countless GANs since use it by default. You watched power iteration’s u,v converge to the true singular value, the W-ellipse’s long axis match σ, and an unnormalized σ explode while SN pinned it at 1 — built entirely by hand. 👉 Tomorrow, Day 59: Dilated Convolutions — grow the receptive field fast without losing resolution.
