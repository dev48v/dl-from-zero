ONE INITIALISATION, TWO PARAMETERISATIONS — IDENTICAL FUNCTION, DIFFERENT EXPERIMENT

There are two ways to make a residual branch start small. Multiply the branch by a constant α = c and leave the initialiser alone, or leave α = 1 and initialise the branch's output matrix at c times its usual scale. At initialisation these are the same function — the branch is linear in that matrix, so c·(W₂a) and (cW₂)·a are the same vector. They are not the same optimisation problem, and the size of the discrepancy depends on which optimiser you use.

The thing a residual stack actually is

A residual block is one line: 

x ← x + α·B(x)

B is whatever the block computes — an attention head, a feed-forward sandwich, a convolution — and α is a scalar that most implementations leave at 1 and never mention. The reason the line is written that way is the backward pass: differentiate it and you get ∂xout/∂xin = I + α·JB. The I is the whole point. Stack L of them and the Jacobian from the top of the network to the bottom contains a term that is the product of L copies of the identity, which is the identity, so there is a path along which the gradient reaches block 0 undamped no matter how deep the stack is.

That is the argument, and it is correct, and it is also conditional on something the argument does not say out loud: the identity has to survive to the next block. Put a normaliser on the main path — which is exactly what Post-LN does, because x ← LN(x + αB(x)) normalises the sum, not the branch — and the Jacobian is no longer I + αJ, it is JLN·(I + αJ). The identity term is now multiplied by JLN, once per block, L times.

The first card measures precisely that, with the branches deleted so that nothing else can be blamed. Zeroing every W₂ makes the block a literal no-op in the Pre-LN arrangement, and the gradient reaching block 0 is bit-identical to the gradient at the top — the ratio is 1 with no tolerance at all, printed as 0.0e+0 error, because the backward pass is genuinely copying the same array down the stack. In the Post-LN arrangement the same deleted branches leave a stack of layer norms applied to a vector that is already normalised, which the forward pass barely notices, and the gradient no longer arrives unchanged. What it does not do is decay geometrically, and that is the card's actual finding. The normaliser's Jacobian is 1/σ times a projection: it removes the component along the all-ones direction and the component along the current activation, so it is singular by construction — but a projection is also idempotent, so applying it to a gradient that already lies in its range does nothing at all. The change fires once, at the top of the stack, and every interior block leaves the gradient identical to the rounding floor. Nothing about that is a pathology of the branch, of the initialisation or of the data, and it is why the fix that worked was moving the LN rather than tuning anything.

Why √L, and what α is for

Forward, the story is the other one. At initialisation the branch weights are independent of everything the stream has accumulated, so the branch output is uncorrelated with the stream it is being added to, and the expected squared norms add: 

Pl+1 = Pl + α²·Pbranch  ⇒  PL = P₀ + L·α²·Pbranch

Power grows linearly in depth, so the norm grows like √L. That is a prediction with no fitted quantity in it: measure P₀ and the branch power at the first block and the whole curve follows, which is what the second card checks — and it is a measurement, not an identity, because the independence assumption is only true at initialisation and only approximately even then, so the honest output is the worst relative deviation rather than a claim of exactness.

The consequence is that the branch's contribution shrinks relative to the stream it is added to. At block L the branch is adding a vector of size α√Pbranch to a stream of size √(Lα²Pbranch), so its relative contribution falls like 1/√L. Deep Pre-LN stacks have a documented tendency for their later blocks to do very little, and this is the arithmetic of it, visible at initialisation with no training at all. Setting α = 1/√L trades one for the other: the total accumulated power becomes depth-independent, so a 40-block stack and a 4-block stack hand the head a stream of the same size, at the cost of every individual block contributing less.

Post-LN never accumulates anything, because the normaliser resets the stream to unit scale at every block. That is the trade in one sentence: Post-LN pays for a stable forward pass with an attenuated backward pass, Pre-LN pays for an undamped backward pass with a forward pass whose scale is a function of depth.

The part that surprised me

GPT-2's initialisation scales the residual output projections by 1/√(2L). Many re-implementations instead multiply the branch by a constant. These are described interchangeably, and at initialisation they are interchangeable, because the branch is linear in its output matrix: c·(W₂a) and (cW₂)·a are the same vector, and the page measures the gap between them as a bound rather than asserting a zero, since it is floating-point summation order and engines round differently.

They are not the same experiment. Write the branch as αW₂a and the gradient with respect to W₂ picks up a factor of α, so under plain SGD the step in W₂ is α times larger and its effect on the function is multiplied by α again: the function-space step scales as α². Fold the same constant into the initialisation instead and the gradient is un-scaled, the step is un-scaled, and the effect on the function is un-scaled. The two exponents differ by two.

Under Adam it is worse in an interesting way. Adam's update is scale-invariant — the first step is exactly −lr·g/(|g|+ε), which does not care that g was multiplied by α — so the α = c parameterisation takes a function-space step proportional to c while the init-scaled parameterisation takes one proportional to 1. The exponents are 2 and 1, measured on the page as a fitted slope rather than quoted from the algebra, and the practical reading is blunt: under Adam, shrinking the initialisation does not shrink the updates at all. A branch initialised 8× small is one Adam step away from being the size Adam wants it to be. An explicit α stays small for as long as you leave it there. Whatever the 1/√(2L) rule buys, it is not the thing an explicit residual scale buys, and the two are not substitutes.

The diagnostic, scored instead of trusted

“Print the gradient norms at each layer and check they are not vanishing” is the first thing anybody does to a deep stack that will not train. It is a number attached to a decision, so it can be scored the same way a classifier is: over a pool of configurations whose true quality is known, how often does it order a pair correctly? The pool here is real — every member is trained to the same budget and scored against an exact floor — and the answer is on the MEASURE tab.

The result to take seriously is not that the diagnostic is bad. It is that the diagnostic is answering a narrower question than the one being asked of it. A gradient ratio tells you whether the backward pass is delivering signal to the bottom of the stack. It has nothing to say about whether the learning rate is survivable, whether the width is sufficient, or whether the model has enough capacity for the function — and a pool that varies those things is asking it to arbitrate cases it cannot see. Hold the things it cannot see fixed and it recovers, which is the control the page reports next to the headline: the same number, inside one placement-and-learning-rate cell, is a different instrument.

The other half of the result is the one that keeps recurring in this series. A cheap probe — the excess after ten steps, one eighth of the pool's eighty-step budget — ranks the pool far better than any static analysis of the initialisation, because it is a measurement of the thing you actually care about rather than a proxy for it. If you can afford to run ten steps, run ten steps.

What is and is not asserted

Three things on this page are identities and are checked without a tolerance beyond floating-point: the Pre-LN zero-branch gradient ratio is exactly 1; the two parameterisations of a scaled residual are the same function at initialisation; and the excess of a model against the true conditional is non-negative, with the teacher's own excess exactly zero.

Everything else is a measurement with a spread, and the page prints the spread. The √L law is reported as a worst relative deviation, not as an equation that holds. The exponents 2 and 1 are fitted slopes with a residual. The trained comparisons are quoted against a noise floor measured by re-running the same configuration under different seeds, and two rows closer together than that floor are one row and are not ranked.

The setup, so the numbers can be checked

The data is a fixed teacher: a 6-block Pre-LN residual net with α = 1/√6 over 6 Gaussian inputs and 4 classes, so p*(y|x) is available in closed form for any x. Training uses labels sampled from p*; evaluation uses p* itself, so a student's held-out score is ∑y p*(y|x)·(−log q(y|x)) averaged over held-out x — an exact expectation, and subtracting the conditional entropy of p* turns it into a mean KL that is zero for the teacher and non-negative for everything else. Students are the same family with the depth, the normaliser placement, the residual scale, the width and the learning rate varied. Forward and backward are both written by hand; the gradients are checked against central differences taken on a second forward pass written independently of the first.

🔨 How it is built

1. A teacher, so the floor is a computation

Every claim on the page is “this model is better than that one”, so “better” has to have an answer. The data-generating process is itself a residual net with fixed weights, which makes p*(y|x) a forward pass rather than an estimate. The held-out score of any student is then ∑y p*(y|x)·(−log q(y|x)) averaged over x — an exact expectation over labels, not an average of sampled ones. Subtract the conditional entropy of p* and it becomes the mean KL, which is exactly 0 for the teacher and provably non-negative for anything else. Both facts are asserted.

Removing the label sampling from the evaluation is not cosmetic. It is what makes the noise floor small enough to rank anything at all: the remaining variation is the held-out input sample and the training seed, and the page measures both separately.

2. Placement is a switch, not three implementations

pre:   x ← x + α·B(LN(x))          + one final LN before the head
post:  x ← LN(x + α·B(x))
none:  x ← x + α·B(x)

One forward function with a switch, and one backward function with the matching switch, so the three arrangements cannot drift apart. The layer-norm gain and bias are initialised to 1 and 0 and consume no random numbers, which means all three placements at the same seed share bit-identical W₁, W₂, Win and Wout. Any difference between the rows is the placement and nothing else.

3. The zero-branch control

The strongest available demonstration that the attenuation belongs to the normaliser is to remove everything else. Setting every W₂ and b₂ to zero makes the branch output identically zero, so x + α·B(x) = x exactly, and the backward pass through the branch contributes exactly zero to the stream gradient. In the Pre-LN arrangement the gradient array reaching block 0 is then the same array that arrived at the top — the ratio is 1 to the bit, and the page prints the deviation as 0.0e+0 rather than as a small number. In the Post-LN arrangement it decays. This is a control, not a simulation of one.

4. Two forward passes, and gradients that have to match both

The cached forward pass is written for speed: it stores the normaliser's intermediates so the backward pass can reuse them. The second forward pass is written from the equations, with its own matrix-vector helper and its own normalisation routine, and shares no code with the first. It is used for two things: an equality check at every setting, and as the function the central differences are taken on. A gradient that agrees with a finite difference of the code that produced it has proved very little; a gradient that agrees with a finite difference of a different implementation has proved something.

5. The exponent, measured rather than derived

A: branch = c·(W₂a),  W₂ ~ σ      B: branch = W₂′a,  W₂′ ~ cσ

Identical functions at initialisation. To measure how differently they move, only W₂ and b₂ are stepped — every other gradient is discarded — and the quantity compared is the change in the logits, which is the change in the function rather than the change in the parameters. The stack is one block deep for this card so the logits are exactly linear in the branch output and the ratio is not contaminated by curvature. The SGD step is −lr·g and the Adam step is written in the closed form the first step actually has, −lr·g/(|g|+ε), so the scale invariance is visible in the source rather than emerging from an optimiser loop. The exponent is a least-squares slope of log(ratio) against log(c) through the origin, reported with its residual.

6. Divergence is recorded, not averaged away

Some configurations in the pool blow up, which is the point of including them. A run whose loss stops being finite is marked diverged, its excess is infinite, and it is ranked last rather than dropped — dropping it would quietly delete the failures the diagnostic is supposed to predict. Comparisons that need finite numbers are stated separately from the ones that do not, so an infinity never lands inside a tolerance.

7. What the verifier does that the page cannot

The Node verifier re-implements the layer norm, its backward pass, the full forward pass, the Adam update, the AUC and the variance-accumulation prediction from the equations, and checks every gradient against central differences taken on its own forward pass rather than the page's second one. It also builds a network with the nonlinearity removed, where the whole model is a product of matrices and the exact gradient is available in closed form, and compares against that. Assertions exist whose only purpose is to fail if the page ever drifts back to claiming that a gradient ratio predicts trainability, or that the two ways of scaling a residual are interchangeable.
