DeepLearningFromZero · Day 54

↗️ ALiBi (Attention with Linear Biases) — self-attention is order-blind: shuffle the tokens and the raw QKᵀ scores come out the same, so a Transformer has to be told where each token sits. The classic recipe adds a positional embedding to every token vector (Day 29’s sinusoidal ladder, or a learned table), but those absolute codes are welded to the exact positions seen during training — feed a model trained at length 1024 a sequence of 3000 tokens and it meets position indices it has never represented, and quality collapses. ALiBi (Press, Smith & Lewis, 2021 — “Train Short, Test Long”) deletes positional embeddings entirely and instead adds a static, non-learned linear bias straight onto the attention scores, before the softmax: for a query at position i attending a key at position j (j ≤ i under a causal mask) it simply subtracts m·(i−j) — a penalty that grows linearly with how far back the key is. There is nothing to learn: m is a fixed per-head slope, and the heads’ slopes form a geometric sequence ½, ¼, ⅛, … = 2−8h/n so some heads attend sharply local (steep slope) while others gaze far (gentle slope) — a built-in multi-scale recency prior. Because the bias depends only on the relative distance i−j and never on an absolute index, the whole pattern is translation-invariant and simply keeps suppressing ever-farther tokens the same way at any length — so a model trained on short sequences extrapolates to far longer ones with no retraining (which is why ALiBi rides in BLOOM, MPT and kin). The softmax turns that straight-line penalty into a clean exponential distance decay, giving each head a bounded effective window. 2 · The per-head slope schedule — a geometric ladder

Each head gets a different fixed slope mh = 2−8h/n. For n = 8 heads that is exactly ½, ¼, ⅛, …, 1/256. Steep slopes = sharp recency (only the last few keys survive); gentle slopes = a head that can still look far back. Every line is the bias −mh·d vs distance d = i−j; the selected head is bold.

3 · Why it extrapolates — train short, test long

Flatten the raw scores and attention is driven purely by the bias: weight falls off as e−m·d with distance. 🔨 Build it yourself

    
ALiBi is a handful of lines bolted onto ordinary attention: no embeddings, no learned parameters, just a fixed bias added to the scores. We’ll build it up: softmax by hand, the causal distance matrix, the geometric per-head slopes, the full ALiBi attention, a multi-head wrapper, and the one property — distance-only — that makes it extrapolate.

    
    
      
  1. 
        
    1
    Softmax & a causal mask, by hand
    
        
    Attention needs a numerically-stable row softmax (subtract the row max first). Causal means a query at i may only see keys j ≤ i; we mark the rest -inf so exp sends them to exactly 0. Sanity: every row sums to 1.
    
        
    import numpy as np

def softmax(row):                      # stable, 1-D
    m = np.max(row[np.isfinite(row)])
    e = np.exp(row - m)                 # -inf -> 0
    return e / e.sum()

def causal_mask(N):                    # True where allowed (j <= i)
    return np.tril(np.ones((N, N), dtype=bool))
    
      
    2. 
      
  2. 
        
    2
    The distance matrix — and the bias
    
        
    The whole of ALiBi lives in one matrix: (i - j), the number of steps a key is behind the query. Multiply by the head slope and negate: bias = -m * (i - j). It’s 0 on the diagonal and grows more negative to the left. No learning, no embeddings.
    
        
    def distance(N):
    i = np.arange(N)[:, None]          # (N,1) query index
    j = np.arange(N)[None, :]          # (1,N) key index
    return i - j                       # (N,N)  >=0 in the causal region

def alibi_bias(N, m):
    return -m * distance(N)            # -m*(i-j) : linear recency penalty
    
      
    3. 
      
  3. 
        
    3
    The per-head slopes — a geometric sequence
    
        
    Each head gets its own slope so the model attends at many scales at once. For n heads (a power of 2) the slopes are the geometric sequence m_h = 2^(-8h/n), i.e. ratio 2^(-8/n) starting from it. For n=8: 1/2, 1/4, …, 1/256.
    
        
    def head_slopes(n):
    start = 2 ** (-8 / n)              # = 2^(-8/n)
    return np.array([start ** (h + 1) for h in range(n)])

head_slopes(8)
# [0.5, 0.25, 0.125, 0.0625, 0.03125, 0.015625, 0.0078125, 0.00390625]
#  steep (local)  ------------------------------->  gentle (far)

    4
    ALiBi attention for one head
    
        
    Ordinary scaled dot-product attention, but add the bias to the scores before the softmax and apply the causal mask. Nothing else about attention changes — and there is no positional embedding added to Q, K or the inputs anywhere.
    
        
    def alibi_attention(Q, K, V, m):
    N, d = Q.shape
    scores = (Q @ K.T) / np.sqrt(d)    # (N,N) raw QK^T
    scores = scores + alibi_bias(N, m) # <-- the ONE new line
    scores[~causal_mask(N)] = -np.inf  # can't see the future
    A = np.stack([softmax(r) for r in scores])
    return A @ V, A                    # output, attention weights

  5. 
        
    5
    Multi-head — one slope per head
    
        
    Run each head with its own slope from the schedule, then concatenate. Cheap heads see only the last token or two; gentle heads keep long-range context alive. The bias is added inside each head; the outputs concat exactly as in vanilla multi-head attention.
    
        
    def multihead_alibi(Qh, Kh, Vh):       # lists of length n_heads
    n = len(Qh)
    slopes = head_slopes(n)
    outs = []
    for h in range(n):
        o, _ = alibi_attention(Qh[h], Kh[h], Vh[h], slopes[h])
        outs.append(o)
    return np.concatenate(outs, axis=-1)   # (N, n*d_head)

    Why it extrapolates — distance, not position
    
        
    The bias reads only i - j. Slide the whole window along the sequence and every entry is unchanged — it is translation-invariant, so length N never appears as an absolute index the way a positional embedding would. Train at 1024, run at 3000: the model only ever sees relative distances, and far ones are simply taxed more.
    
        
    # translation invariance: bias(i,j) depends ONLY on (i-j)
b = alibi_bias(8, 0.25)
assert np.allclose(b[7,3], b[6,2])     # same distance 4 -> same bias
assert np.allclose(b[5,5], 0.0)        # distance 0 -> no penalty

# softmax turns the LINEAR bias into an EXPONENTIAL decay in distance:
#   weight(d)  ∝  exp(-m * d)          # bounded effective window ~ 1/m
# no absolute position is ever represented -> test length > train length OK

🎉 Day 54 of DeepLearningFromZero done.
ALiBi gives a Transformer position without positional embeddings: it adds a fixed, unlearned bias −m·(i−j) straight onto the attention scores before the softmax, penalising each key in proportion to how far behind the query it sits. Every head owns a slope from the geometric schedule 2−8h/n (½,¼,…), so the model attends at many recency scales at once, and the softmax turns that straight-line penalty into an exponential distance decay with a bounded window. Because the bias depends only on the relative distance i−j and never on an absolute index, it is translation-invariant — a model trained short extrapolates to far longer contexts, the property that put ALiBi into BLOOM and MPT. Unlike sinusoidal (absolute, added to inputs) or RoPE (relative, applied by rotating Q/K), ALiBi needs no embedding table and no rotation — just one added matrix. 👉 Tomorrow, Day 55: Mixture-of-Experts — route each token to a few expert MLPs for huge capacity at a cheap per-token cost.
