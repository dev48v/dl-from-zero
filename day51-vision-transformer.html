DeepLearningFromZero · Day 51

🌆 Vision Transformer (ViT) — the transformer was built for sequences of words, so ViT’s one radical move is to make an image look like a sentence: chop it into a grid of fixed 16×16 patches (“an image is worth 16×16 words”), flatten each patch’s 16·16·3 = 768 pixels into a vector, and linearly project it to a D-dim token — a learned “patch embedding” that is literally just a Conv2d(3, D, kernel=16, stride=16). Prepend one extra learnable [CLS] token (its final state is the whole-image summary the classifier reads), add positional embeddings so the model knows where each patch sat (a bag of patches has no inherent order), and feed the N+1 tokens through a completely standard transformer encoder — the exact multi-head self-attention + MLP blocks from language, no convolutions anywhere. Every patch attends to every other patch from layer 1, so ViT has a global receptive field immediately, where a CNN grows its view slowly through stacked local filters. The catch is inductive bias: a conv bakes in locality and translation-equivariance (nearby pixels relate; a cat is a cat wherever it appears), and ViT throws all of that away — it must learn those regularities from data, which makes it data-hungry (plain ViT only beats strong CNNs after pre-training on ~300M images like JFT-300M; on ImageNet-alone it underperforms), later fixed by heavy augmentation + distillation (DeiT). Self-attention is O(N²) in the token count, so the patch size is the key knob: smaller patches → more tokens → finer detail but a quadratic blow-up in compute. A ViT never sees a whole image — it sees a sequence of non-overlapping patches. With a 224×224 image and patch size P, you get a (224/P)×(224/P) grid of N patches, then prepend a [CLS] token for a sequence of L = N+1 tokens. Smaller patches capture finer detail but explode the token count — and self-attention is O(L²), so halving P roughly 16×s the attention cost.

🔨 Build it yourself

    
A Vision Transformer is startlingly little code — it’s a standard transformer encoder with a patch-embedding front-end. We’ll build it piece by piece: patch embedding as a strided conv, the [CLS] token and positional embeddings, one encoder block (pre-norm MHSA + MLP), the classification head, and finally the whole forward — the ViT-B/16 config from the paper.

    
    
      
  1. 
        
    1
    Patch embedding = a strided convolution
    
        
    Splitting into patches and linearly projecting each one is exactly a Conv2d with kernel_size = stride = P: each kernel position covers one non-overlapping patch and outputs a D-vector. No loops needed — one conv turns (B,3,224,224) into (B,D,14,14).
    
        
    import torch, torch.nn as nn

class PatchEmbed(nn.Module):
    def __init__(self, img=224, P=16, in_ch=3, D=768):
        super().__init__()
        self.n_patches = (img // P) ** 2          # 14*14 = 196
        # kernel = stride = P  ->  one D-vector per PxP patch
        self.proj = nn.Conv2d(in_ch, D, kernel_size=P, stride=P)

    def forward(self, x):                          # x: (B, 3, 224, 224)
        x = self.proj(x)                           # (B, D, 14, 14)
        x = x.flatten(2).transpose(1, 2)           # (B, 196, D)  tokens
        return x

  2. 
        
    2
    Prepend the [CLS] token + add positional embeddings
    
        
    A single learnable [CLS] vector is prepended to the 196 patch tokens (its output becomes the image summary). Then a learnable positional embedding — one per slot, including [CLS] — is added, because self-attention is permutation-invariant and would otherwise not know a patch’s location.
    
        
    self.cls = nn.Parameter(torch.zeros(1, 1, D))          # 1 learnable token
self.pos = nn.Parameter(torch.zeros(1, 1 + n_patches, D))  # learned positions

def add_tokens(self, x):                    # x: (B, 196, D)
    B = x.shape[0]
    cls = self.cls.expand(B, -1, -1)        # (B, 1, D)
    x = torch.cat([cls, x], dim=1)          # (B, 197, D)  <- [CLS] + patches
    x = x + self.pos                        # add position to every token
    return x
    
      
    3. 
      
  3. 
        
    3
    Multi-head self-attention over the patches
    
        
    Identical to the language transformer (Day 30). Project tokens to Q, K, V; every token attends to every other via scaled dot-product softmax; concat the heads and project back. This is the only place patches exchange information — and they do it globally, all-to-all, from the first layer.
    
        
    class MHSA(nn.Module):
    def __init__(self, D=768, heads=12):
        super().__init__()
        self.h, self.dh = heads, D // heads
        self.qkv = nn.Linear(D, 3 * D)
        self.out = nn.Linear(D, D)

    def forward(self, x):                       # (B, L, D)
        B, L, D = x.shape
        qkv = self.qkv(x).reshape(B, L, 3, self.h, self.dh).permute(2,0,3,1,4)
        q, k, v = qkv[0], qkv[1], qkv[2]        # (B, h, L, dh)
        att = (q @ k.transpose(-2,-1)) / self.dh**0.5   # (B, h, L, L)
        att = att.softmax(dim=-1)               # every token over every token
        x = (att @ v).transpose(1,2).reshape(B, L, D)
        return self.out(x)
    
      
    4. 
      
  4. 
        
    4
    One encoder block — pre-norm, residual, MLP
    
        
    The standard block: LayerNorm → attention → +residual, then LayerNorm → MLP(GELU) → +residual. ViT uses pre-norm (LN before each sub-layer) for stable deep training. Stack 12 of these for ViT-Base. Nothing here is vision-specific — it’s the same block as GPT/BERT.
    
        
    class Block(nn.Module):
    def __init__(self, D=768, heads=12, mlp=4):
        super().__init__()
        self.n1, self.n2 = nn.LayerNorm(D), nn.LayerNorm(D)
        self.attn = MHSA(D, heads)
        self.mlp = nn.Sequential(
            nn.Linear(D, mlp*D), nn.GELU(), nn.Linear(mlp*D, D))

    def forward(self, x):
        x = x + self.attn(self.n1(x))     # pre-norm attention + residual
        x = x + self.mlp(self.n2(x))      # pre-norm MLP + residual
        return x
    
      
    5. 
      
  5. 
        
    5
    The whole ViT — classify from [CLS]
    
        
    Assemble: patch-embed → add [CLS] + positions → 12 blocks → final LayerNorm → take only the [CLS] token’s output → a linear head to class logits. That single token, refined by attending to all patches, carries the whole-image decision.
    
        
    class ViT(nn.Module):
    def __init__(self, img=224, P=16, D=768, depth=12, heads=12, classes=1000):
        super().__init__()
        self.patch = PatchEmbed(img, P, 3, D)
        n = self.patch.n_patches
        self.cls = nn.Parameter(torch.zeros(1, 1, D))
        self.pos = nn.Parameter(torch.zeros(1, 1 + n, D))
        self.blocks = nn.ModuleList([Block(D, heads) for _ in range(depth)])
        self.norm = nn.LayerNorm(D)
        self.head = nn.Linear(D, classes)

    def forward(self, x):
        x = self.patch(x)                          # (B, 196, D)
        cls = self.cls.expand(x.shape[0], -1, -1)
        x = torch.cat([cls, x], 1) + self.pos      # (B, 197, D)
        for blk in self.blocks: x = blk(x)
        x = self.norm(x)
        return self.head(x[:, 0])                  # <- [CLS] token only

    Run it — and the data-hungriness caveat
    
        
    A forward pass is one line. But training matters: with no convolutional inductive bias, plain ViT needs either huge pre-training (JFT-300M → then fine-tune) or, on ImageNet-scale data, heavy augmentation + regularization + distillation (the DeiT recipe) to match a good CNN. This is the single most important practical fact about ViT.
    
        
    model = ViT(img=224, P=16, D=768, depth=12, heads=12, classes=1000)
x = torch.randn(4, 3, 224, 224)          # a batch of 4 images
logits = model(x)                        # (4, 1000)  -> class scores

# ViT-B/16: ~86M params, 196 patch tokens + 1 [CLS] = 197.
# NO conv locality bias  ->  data-hungry:
#   * pre-train on JFT-300M, then fine-tune  (original paper), OR
#   * DeiT recipe: strong aug + distillation to train on ImageNet alone.
# Optimizer: AdamW, cosine schedule, big weight decay.

🎉 Day 51 of DeepLearningFromZero done.
The Vision Transformer applies the language transformer to images by making an image look like a sentence: cut it into fixed 16×16 patches, flatten + linearly embed each into a token (literally a Conv2d(3,D,16,16)), prepend a learnable [CLS] token, add positional embeddings, and push the N+1 tokens through a standard transformer encoder — then classify from the [CLS] output. Because attention is all-to-all, ViT sees globally from layer 1, unlike a CNN’s slowly-growing receptive field — but it also lacks the conv’s built-in locality & translation-equivariance inductive bias, so it’s data-hungry and only shines with huge pre-training (JFT-300M) or the DeiT augmentation+distillation recipe. The patch size is the master knob: smaller patches mean more tokens, finer detail, and an O(N²) compute blow-up. ViT is now the backbone under CLIP, DINO, MAE, SAM and most modern vision. 👉 Tomorrow, Day 52: CLIP — train an image encoder (a ViT!) and a text encoder together with a contrastive loss so pictures and captions land in one shared space, unlocking zero-shot classification from plain-English labels.
