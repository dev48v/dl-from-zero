DeepLearningFromZero · Day 44

✂️ Gradient Clipping — deep and recurrent nets learn by multiplying gradients back through many layers or time-steps, and multiplication is a runaway process: if the repeated Jacobian has a spectral radius above 1, the gradient grows like ρT and a single step can be astronomically large. In the loss landscape this shows up as steep walls (“cliffs”) — the gradient near a wall is enormous, so a normal-sized step doesn’t descend, it catapults the weights to a wild point where the next forward pass overflows to Infinity and the loss becomes NaN. One bad step and training is dead. Gradient clipping is the cheap, standard rescue: cap the gradient before the optimiser step. Two flavours. Clip-by-value clamps every element into [−c, c] — simple, but clamping components unevenly bends the update off the true descent direction. Clip-by-norm looks at the whole gradient vector’s length ‖g‖ and, only if it exceeds a threshold τ, rescales the entire vector by τ/‖g‖. Because that is a single positive scalar multiply, the direction is exactly preserved — you take a shorter step the same way, never off a cliff. Pick τ by watching the gradient-norm during a healthy run and clipping the rare spikes (1.0 is the transformer default; 5–10 for RNNs). Below is a real tiny recurrent net doing back-prop-through-time on a genuinely explosive setup: with clipping off the gradient norm and loss rocket to NaN in a few steps; switch clip-by-norm on and the very same net stays finite and converges.

🔨 Build it yourself

    
Gradient clipping is two lines of code that stand between a working training run and a screenful of NaN. We start by watching a loop explode, add the value clip and the norm clip, get the placement exactly right (after backward(), before step()), see how PyTorch clips the global norm across every parameter at once, learn to pick the threshold, implement the norm clip by hand to demystify it, and finish with the mixed-precision gotcha plus where clipping sits among the real cures.

    1
    See it explode — the loop that ends in NaN
    
        
    A deep or recurrent net can produce a single gradient thousands of times larger than usual. Take one un-clipped SGD step with it and the weights fly off; the next forward pass overflows to inf, and inf − inf makes the loss NaN. Once any parameter is NaN it spreads to all of them and the run is dead — no learning-rate tweak recovers it.
    
        
    for x, y in loader:
    opt.zero_grad()
    loss = criterion(model(x), y)
    loss.backward()              # a rare step yields a HUGE gradient
    opt.step()                   # one giant update -> weights blow up
    # a few steps later:  loss = nan  ->  training is destroyed

    2
    Clip by value — clamp every element
    
        
    The bluntest fix: force every gradient component into [−c, c]. Nothing can ever be larger than c, so the step is bounded. It works and it never NaNs — but clamping components by different amounts changes their ratios, so the update no longer points along true steepest descent. Fine as a safety net, less principled than the norm clip.
    
        
    loss.backward()
torch.nn.utils.clip_grad_value_(model.parameters(), clip_value=1.0)
opt.step()
# every g_i is now max(-1.0, min(1.0, g_i))  — element-wise cap
    
      
    3. 
      
  3. 
        
    3
    Clip by norm — rescale the whole vector, keep the direction
    
        
    Measure the length of the entire gradient, ‖g‖. If it is under the threshold τ, leave it alone. If it is over, multiply the whole vector by τ/‖g‖ so its new length is exactly τ. That factor is a single positive scalar, so every component shrinks by the same ratio — the update points in exactly the same direction, just shorter. This is the default choice for RNNs and transformers.
    
        
    loss.backward()
torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)
opt.step()
#   if ‖g‖ > τ:   g  <-  g * (τ / ‖g‖)     # same direction, length = τ
#   else:         g unchanged
    
      
    4. 
      
  4. 
        
    4
    Placement — after backward, before step
    
        
    Clipping edits .grad, so it must run after loss.backward() has filled the gradients and before opt.step() uses them. Put it earlier and there is nothing to clip; put it later and the giant step already happened. One line, in the right place.
    
        
    opt.zero_grad()
loss = criterion(model(x), y)
loss.backward()                                  # 1) grads exist
torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0)   # 2) clip them
opt.step()                                        # 3) safe update

  5. 
        
    5
    Global norm — one length over ALL parameters
    
        
    clip_grad_norm_ does not clip each tensor separately — it concatenates every parameter’s gradient into one giant vector, takes that single total norm, and rescales everything by one shared factor. This preserves the direction of the entire update, not just per-layer, and it returns the pre-clip total norm — the perfect thing to log and watch.
    
        
    # total_norm = sqrt( Σ over all params  ‖g_p‖² )
total_norm = torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)
print(total_norm)     # log this every step to see your spikes
# one factor τ/total_norm scales every gradient tensor together

    Choosing the threshold τ
    
        
    Don’t guess — measure. Log the total grad-norm for a few hundred steps of a stable run and look at its distribution. Set τ a bit above the typical value so it only bites the rare spikes. Too low and you throttle every honest update (slow, biased training); too high and the cliffs get through. Common defaults: 1.0 for transformers/LLMs, 5–10 for RNNs/LSTMs.
    
        
    norms = []
for step in warmup_steps:
    loss.backward()
    norms.append(torch.nn.utils.clip_grad_norm_(model.parameters(), 1e9))  # measure only
    opt.step()
tau = np.quantile(norms, 0.90)     # clip the top ~10% of spikes
# transformers ~1.0 · RNNs ~5-10 · tune from the histogram

    Do it by hand — demystify the one line
    
        
    There is no magic. Sum the squared gradients across all parameters, square-root for the total norm, and if it exceeds τ scale every gradient in place by τ/‖g‖. (A tiny 1e-6 guards against divide-by-zero.) This is exactly what the library call does.
    
        
    def clip_grad_norm_manual(params, tau):
    params = [p for p in params if p.grad is not None]
    total = torch.sqrt(sum((p.grad**2).sum() for p in params))
    if total > tau:
        scale = tau / (total + 1e-6)
        for p in params:
            p.grad.mul_(scale)          # same direction, length now = tau
    return total

    Mixed precision, and clipping as one tool among many
    
        
    With AMP / GradScaler the gradients are scaled up, so you must unscale_ before clipping or you’ll clip the wrong magnitude. And remember what clipping is: a band-aid on the symptom. The deeper cures for exploding gradients are good initialisation, normalisation (Batch/Layer/RMSNorm), residual connections, and gated units (LSTM/GRU). Use those to reduce spikes — and keep the clip as a cheap seatbelt for the ones that remain.
    
        
    scaler.scale(loss).backward()
scaler.unscale_(opt)                                   # back to true scale
torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0)  # THEN clip
scaler.step(opt); scaler.update()
# clipping treats the symptom; init + norm + residuals + gating cure the cause

🎉 Day 44 of DeepLearningFromZero done.
Gradient clipping is the seatbelt of deep-net training. Back-prop multiplies gradients through many layers or time-steps, so when the repeated Jacobian’s spectral radius exceeds 1 the gradient can grow like ρT and a single step off a loss cliff sends the weights — and the loss — to NaN. Capping the gradient first fixes it: clip-by-value clamps each element into [−c,c] (simple, but it bends the update), while clip-by-norm rescales the whole vector by τ/‖g‖ only when ‖g‖>τ — a single scalar multiply that preserves the descent direction exactly, which is why it’s the default for RNNs and transformers. You saw a real 4-unit RNN hit NaN in a few steps with clipping off, and the same net converge with clip-by-norm on and a 0.00° direction change. Choose τ from the grad-norm histogram (≈1.0 for transformers, 5–10 for RNNs), and remember it’s a band-aid — init, normalisation, residuals and gating are the real cures. 👉 Tomorrow, Day 45: Mixed-Precision Training — fp16/bf16, loss scaling with GradScaler, and how it pairs with the clipping you just learned.
