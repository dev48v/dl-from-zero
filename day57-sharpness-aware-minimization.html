DeepLearningFromZero · Day 57

🏔 Sharpness-Aware Minimization (SAM) — ordinary training minimizes only the loss L(w) at a single point in weight space, so it happily dives into the deepest hole it finds — often a sharp, narrow minimum where the loss is tiny at the bottom but shoots up the instant the weights are nudged. The catch: the test loss is a slightly shifted copy of the train loss, and a sharp minimum sits on a knife-edge — a small shift and the loss explodes, so it generalizes badly. A wide, flat minimum is robust: perturb the weights and the loss barely moves, so the train and test surfaces stay close and it generalizes well. SAM (Foret et al., 2021) bakes that in by changing the objective from “low loss” to “low loss in a whole ρ-neighbourhood”: minw max∥δ∥≤ρ L(w+δ). The inner max asks “what is the worst loss within radius ρ of me?” — and its first-order answer is a single step up the normalized gradient δ̂ = ρ·∇L/∥∇L∥. So each SAM update is two gradient evaluations: (1) climb to the worst nearby point wadv = w + ρ·ĝ, (2) take the gradient there and descend it from the original w. That perturbed gradient is the gradient of the worst-case loss, so it fights sharpness directly — it costs about 2× a normal step and simply wraps any base optimizer (SGD, Adam). Below is a real 2-D loss landscape with a sharp deep dip and a wide flat basin: drop a start point, tune ρ and the learning rate, and watch plain SGD fall straight into the sharp dip while SAM’s worst-case step climbs the ρ-ball, refuses the dip, and settles in the flat basin — every gradient, the normalized ascent, the two-step update and the contours computed by hand, no libraries.

🔨 Build it yourself

    
SAM is a tiny wrapper around any base optimizer. We’ll build the whole thing from scratch: a toy 2-D loss and its gradient, the normalized ascent step that solves the inner max, the two-step ascent–descent update, a plain-SGD baseline for contrast, a genuine sharpness measure, and the base-optimizer wrapper form (first_step / second_step) exactly as PyTorch SAM does it — every gradient by hand.

    
    
      
  1. 
        
    1
    The loss and its gradient
    
        
    Any differentiable loss works. Here a hand-crafted 2-D surface: a gentle bowl plus two Gaussian wells — one narrow (sharp) and one wide (flat). We take the gradient analytically, but a black-box finite-difference gradient works identically.
    
        
    import numpy as np

def loss(w):                       # w = [x, y]
    x, y = w
    bowl  = 0.04*(x*x + y*y)
    sharp = 0.75*np.exp(-(((x+1.5)**2)+(y**2))/(2*0.26**2))   # narrow  -> sharp
    flat  = 1.10*np.exp(-(((x-0.7)**2)+(y**2))/(2*1.50**2))   # wide    -> flat
    return bowl - sharp - flat

def grad(w):                       # analytic gradient of loss(w)
    x, y = w
    es = np.exp(-(((x+1.5)**2)+(y**2))/(2*0.26**2))
    ef = np.exp(-(((x-0.7)**2)+(y**2))/(2*1.50**2))
    gx = 0.08*x + 0.75*((x+1.5)/0.26**2)*es + 1.10*((x-0.7)/1.50**2)*ef
    gy = 0.08*y + 0.75*( y      /0.26**2)*es + 1.10*( y      /1.50**2)*ef
    return np.array([gx, gy])

    2
    The inner max → a normalized ascent step
    
        
    SAM wants the worst point inside the ρ-ball: max∥δ∥≤ρ L(w+δ). First order, L(w+δ)≈L(w)+δ·∇L, which is largest when δ points along ∇L. Normalize it to length ρ — a single unit-norm ascent, no inner loop.
    
        
    def ascent(w, rho):
    g  = grad(w)
    n  = np.linalg.norm(g) + 1e-12   # guard the zero-gradient case
    eps = rho * g / n                # ∥eps∥ == rho exactly (unit dir x rho)
    return w + eps                   # w_adv: the worst nearby point
    
      
    3. 
      
  3. 
        
    3
    The SAM update — ascend, then descend the gradient there
    
        
    The key move: climb to w_adv = w + ρ·ĝ, take the gradient at w_adv, then step from the original w along that perturbed gradient. It is the gradient of the worst-case loss, so descending it flattens the neighbourhood, not just the point.
    
        
    def sam_step(w, lr, rho):
    w_adv = ascent(w, rho)           # step 1: worst point in the rho-ball
    g_adv = grad(w_adv)              # step 2: gradient THERE (2nd eval)
    return w - lr * g_adv            #         descend it from the ORIGINAL w

    Plain SGD — the baseline
    
        
    For contrast, ordinary SGD uses the gradient at w (one eval) and knows nothing about the neighbourhood — so it dives into whatever minimum is nearest, sharp or not.
    
        
    def sgd_step(w, lr):
    return w - lr * grad(w)          # gradient at w; sharpness invisible

  5. 
        
    5
    Measuring sharpness
    
        
    Sharpness is exactly the inner max minus the centre: how far the loss can climb within ρ. Sample the ρ-sphere (its max lies on the boundary) — a large value means a sharp minimum, near zero means a flat one.
    
        
    def sharpness(w, rho, n=180):
    l0 = loss(w)
    ring = [loss(w + rho*np.array([np.cos(a), np.sin(a)]))
            for a in np.linspace(0, 2*np.pi, n, endpoint=False)]
    return max(ring) - l0            # worst climb over the rho-ball

    The base-optimizer wrapper form
    
        
    Real SAM wraps any optimizer. first_step perturbs the weights to w_adv and stashes the offset; second_step restores w, then lets the base optimizer (SGD, Adam, …) apply its normal update using the gradient computed at w_adv. Two forward/backward passes per step.
    
        
    class SAM:
    def __init__(self, params, base_opt, rho=0.05):
        self.base, self.rho, self.e = base_opt, rho, None
    def first_step(self, w):
        g = grad(w)
        self.e = self.rho * g / (np.linalg.norm(g) + 1e-12)
        return w + self.e            # climb to w_adv; keep the offset e
    def second_step(self, w_adv):
        w = w_adv - self.e           # undo the climb -> back to original w
        g_adv = grad(w_adv)          # gradient at the perturbed point
        return self.base.update(w, g_adv)   # base optimizer's own rule

# training:  w_adv = sam.first_step(w);  w = sam.second_step(w_adv)

🎉 Day 57 of DeepLearningFromZero done.
Sharpness-Aware Minimization swaps the training target from the loss at a single point to the worst loss in a ρ-neighbourhood: minw max∥δ∥≤ρ L(w+δ). The inner max is solved in closed form by one normalized ascent δ̂=ρ·∇L/∥∇L∥, so each step is two gradient evaluations: climb to the worst nearby point wadv, then descend the gradient computed there from the original w. Because that perturbed gradient is the gradient of the worst-case loss, SAM is pushed away from sharp, fragile minima toward wide, flat ones that survive the train→test shift — measurably better generalization for a ≈2× compute cost, and it wraps any base optimizer (SGD, Adam). Follow-ups sharpen the idea: ASAM makes ρ adaptive/scale-invariant, and efficient/Look-SAM variants amortize the extra pass. You watched plain SGD fall into the sharp dip while SAM stepped over the ridge into the flat basin, its sharpness gauge collapsing — the whole method built by hand. 👉 Tomorrow, Day 58: Spectral Normalization — cap each layer’s Lipschitz constant to stabilize GAN training.
