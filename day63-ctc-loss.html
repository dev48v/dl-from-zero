DEEPLEARNINGFROMZERO · DAY 63

🔤 CTC loss — how a network that emits T frames is trained against a label of length U, when nobody told it which frame belongs to which letter. Every earlier day in this series had an output that lined up with a target. Speech, handwriting and OCR do not: the alignment is latent, and labelling it by hand is the expensive thing CTC exists to avoid. The answer is to define the loss as the probability of every alignment at once — insert a blank symbol, allow repeats, sum over all valid paths — and compute that sum in O(T·U) with a forward–backward recursion instead of enumerating exponentially many paths. This page implements the recursion, then does the thing that makes it believable: for small T and U it brute-force enumerates every path and checks the recursion agrees to floating-point noise. Gradients are checked the same way, against finite differences. Then the parts people get wrong: log-space arithmetic, the a-a versus a-b transition rule, and why greedy decoding is not argmax over labellings.

A random emission matrix is generated for T frames over the alphabet plus a blank. Both the forward recursion and a full path enumeration run on it, live.

FORWARD RECURSION

—

O(T·U), log-space.

BRUTE-FORCE ENUMERATION

—

— paths summed, no recursion.

AGREEMENT

—

Relative difference. Should be floating-point noise.

THE ALPHA TRELLIS (probabilities, not logs)

Rows are the extended label blank c blank a blank t blank; columns are frames. Each cell is the total probability of all prefixes that reach that symbol by that frame. The answer is the sum of the last two cells in the final column — the label may finish on its last letter or on a trailing blank.

CHECK THE GRADIENT

Analytic gradients from the forward–backward pass, compared against central finite differences on the same emissions. This is the check that catches a wrong transition rule, which otherwise trains to something that merely looks plausible. 


      


      

        
DECODING

        

          Greedy decoding takes the argmax per frame, then collapses repeats and removes blanks. That
          is not the most likely labelling — several paths can collapse to the same string,
          and their probabilities add. This finds both.
        

        
        

      


    

  






  

    


      
The label is short. The output is long. Nobody aligned them.


      
An acoustic model emits a distribution over symbols every 10ms — call it T = 300 frames for
      three seconds of speech. The transcript is "cat": U = 3. To train with cross-entropy you would
      need to know that frames 0–40 are "c", 41–95 are "a", and so on. That labelling is exactly what
      nobody has, and producing it by hand is the cost CTC removes.


      
Two devices, and everything follows

      
    
        
  1. Add a blank symbol, written -. It means "no output here".
    2. 
        
  2. Define a collapse: merge runs of identical symbols, then delete blanks.
    3. 
      

      
So cc-aa-t, -c-a-t- and ccaaat all collapse to
      cat. The loss is the total probability of every frame-path that collapses
      to the target.


      

        
P(cat | x) = Σ over paths π that collapse to "cat" of Πt yπ(t)t

      


      
Why the blank is not optional

      
Without a blank you cannot spell a word with a doubled letter. Collapse merges repeats, so
      ll would always become l — "hello" would be unreachable. The blank
      gives you a separator: l-l collapses to ll. That is why the extended
      label interleaves blanks around every symbol, and why the trellis has 2U+1 rows rather than U.


      
The transition rule, which is the whole algorithm

      
In the extended label - c - a - t -, from state s at frame t
      you may come from:

      
    
        
  • s — stay (repeat the same symbol)
    • 
        
  • s−1 — advance one
    • 
        
  • s−2 — skip a blank, but only if the current symbol is not blank
        and is different from the symbol at s−2
    • 
      

      

        
That last condition is the one everyone gets wrong. Skipping the blank
        between two identical letters would collapse them into one, so the path would spell
        cat when the label is ccat. Get it wrong and the loss still
        decreases during training — it is just computing the probability of the wrong set of paths.
        Which is precisely why this page checks the recursion against brute force.

      


      
Work in log space, always

      
These are products of 300 probabilities. In float64 that underflows to exactly zero well
      before you finish, and then the gradient is 0/0. So every quantity is a log-probability and
      addition becomes logaddexp(a,b) = max + log1p(exp(−|a−b|)), which is stable. The
      page uses log space throughout and only exponentiates for display.


      
Decoding is a separate problem

      
Greedy decoding — argmax each frame, then collapse — gives you the most likely
      path. It does not give the most likely labelling, because many paths collapse
      to the same string and their probabilities add. A labelling made of many mediocre paths can
      beat one made of a single excellent path. That is what prefix beam search is for, and the
      RUN IT tab shows a case where greedy and true-best disagree.


      
The assumption CTC makes, stated plainly

      
CTC assumes outputs are conditionally independent across frames given the
      input. That is false for language — the letter after "ca" is not independent of "ca" — and it
      is why CTC systems are paired with an external language model. It is not a flaw to hide; it is
      the trade that makes the sum over alignments tractable in the first place.


    

  






  

    


      
🔨 Build it yourself


      
1. Log-space addition, first

      
const NEG_INF = -Infinity;
function logAdd(a, b){
  if (a === NEG_INF) return b;
  if (b === NEG_INF) return a;
  const hi = Math.max(a, b), lo = Math.min(a, b);
  return hi + Math.log1p(Math.exp(lo - hi));      // never exp() a large positive
}


      
2. Extend the label with blanks

      
// "cat" -> [-, c, -, a, -, t, -]   length 2U+1
function extend(label, blank){
  const ext = [blank];
  for (const c of label){ ext.push(c); ext.push(blank); }
  return ext;
}


      
3. The forward recursion

      
function forward(logProbs, ext, idx){
  const T = logProbs.length, S = ext.length;
  const a = Array.from({length:T}, () => new Array(S).fill(NEG_INF));
  a[0][0] = logProbs[0][idx(ext[0])];
  if (S > 1) a[0][1] = logProbs[0][idx(ext[1])];

  for (let t = 1; t < T; t++){
    for (let s = 0; s < S; s++){
      let v = a[t-1][s];                                  // stay
      if (s > 0) v = logAdd(v, a[t-1][s-1]);              // advance
      // skip a blank ONLY if this symbol is not blank and differs from s-2
      if (s > 1 && ext[s] !== BLANK && ext[s] !== ext[s-2])
        v = logAdd(v, a[t-1][s-2]);
      a[t][s] = v + logProbs[t][idx(ext[s])];
    }
  }
  return a;
}
// loss = -logAdd(a[T-1][S-1], a[T-1][S-2])


      
4. Now prove it, do not trust it

      
For small T, enumerate every path in the alphabetT, collapse each one, and sum the
      probability of those that collapse to the target. No recursion, no dynamic programming, no
      shared code with step 3 — so agreement is evidence.

      
function bruteForce(probs, target, symbols){
  let total = 0, paths = 0;
  const T = probs.length;
  const rec = (t, path, p) => {
    if (t === T){ paths++; if (collapse(path) === target) total += p; return; }
    for (let k = 0; k < symbols.length; k++) rec(t+1, path + symbols[k], p * probs[t][k]);
  };
  rec(0, "", 1);
  return { total, paths };
}

      
This is exponential and that is fine — it is a test, not a trainer. Cap T at about 8 and
      you get a genuine oracle for the recursion.


      
5. Break it on purpose, to see the test work

      
Drop the ext[s] !== ext[s-2] condition and re-run. The recursion still produces
      a smooth, plausible-looking number — and brute force immediately disagrees. That is the whole
      value of an independent oracle: the bug does not announce itself.
